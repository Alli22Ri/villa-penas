# Villa Peñas — Consumo de API REST

Aplicación web desarrollada en *React + TypeScript + Vite* para consultar los paquetes turísticos públicos de Villa Peñas.

## Ejecución local

1.⁠ ⁠Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar el servidor de desarrollo:
npm run dev
3. Abrir en el navegador:
http://localhost:5173/
